## 처음 실행하는 법

1. **CaptureNote-mac.dmg** 를 열고 **캡처노트** 를 **응용 프로그램** 폴더로 끌어다 놓기
2. 응용 프로그램 폴더에서 **캡처노트** 두 번 누르기
3. "확인할 수 없습니다" 창이 뜨면 **[완료]** → **시스템 설정 → 개인정보 보호 및 보안** → 맨 아래 **[그래도 열기]** (처음 한 번만)
4. 뜨는 **처음 설정** 창에서 **화면 기록** 을 **[켜러 가기]** → 캡처노트 켜기 → **⌘Q** 로 캡처노트를 완전히 종료했다가 다시 열기
5. **⌘⇧D** 로 찍어 보고 **⌘V** 로 붙여넣기

## 이미 받으신 분: 새 버전으로 바꾸기 (0.7.0부터)

1. 새 버전이 나오면 **"새 버전 X · 눌러서 업데이트"** 알림이 떠요. 또는 메뉴 막대 캡처노트 아이콘 → **[업데이트 확인]**
2. **[업데이트]** 를 누르면 새 버전을 받아 확인한 뒤 바꾸고 다시 켜요
3. 다시 켜지면 뜨는 **처음 설정** 창에서 화면 기록 ✓ 확인 (비어 있으면 [켜러 가기])

자동으로 안 되면 새 dmg를 받아 캡처노트를 응용 프로그램 폴더로 끌어다 놓고 **[대치]** 해 주세요. 0.6.x를 쓰던 분은 이 방법으로 한 번만 바꾸면 그다음부터 [업데이트]로 돼요.

## 쓰는 법

- **⌘⇧D** → 드래그: 찍고 바로 복사, **⌘V** 로 붙여넣기
- **⌘⇧F**: 전체 화면 / **⌘⇧S**: 스크롤 캡처 (드래그 또는 한 번 클릭, 끝까지 자동으로 내려가요)

## 알려 드려요

- 무료로, 있는 그대로 제공돼요. 사용하면서 생긴 오류·데이터 손실·손해는 책임지지 않아요.
- 개인정보를 받거나 모으지 않아요. 회원가입·로그인이 없고, 캡처와 글자 인식 결과를 인터넷으로 보내지 않아요.
- 캡처한 내용의 저작권·개인정보·회사 보안 규정은 쓰는 분이 지켜 주세요.
- 블러·모자이크·개인정보 자동 찾기는 놓칠 수 있어요. 공유하기 전에 꼭 직접 확인해 주세요.
- 날짜·시간 표시는 Mac 시계를 보여 줄 뿐, 증명이나 위조 방지 기능이 아니에요.
- 기능과 배포는 예고 없이 바뀌거나 중단될 수 있어요. 공식 배포처(이 페이지의 Releases)가 아닌 곳에서 받은 파일은 확인해 드릴 수 없어요.
